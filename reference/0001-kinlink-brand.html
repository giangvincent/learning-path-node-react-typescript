KinLink brand: the mark, the palette, the rules

The visual identity, compressed to one screen. Come back here whenever you style a component.

Vocabulary: GLOSSARY.md Pipeline exercise: week 1–2, in client/src/brand/

1. What the mark is

A pixel DNA double helix on a near-black field. Two strands cross twice — once near the top, once near the bottom — and bow apart into a loop in the middle. Gold rungs bridge the strands. Everything is drawn on a single square grid, so every edge is a straight, unaliased run of whole cells.

The mark carries the product idea: family + genetics + generations + connection. It is the textless symbol; the logo is the mark plus the wordmark.

Rule

Teal means structure and connection. Gold means importance. If everything is gold, nothing is. One gold thing per screen.

Pixel personality for the brand voice, a modern sans for everything you read.

4. Where the brand lives in the code

One folder, one source of truth. The client imports it; nothing re-declares a hex. 

client/src/brand/
├── tokens.ts            brandColors, the typed palette    (hand written)
├── DnaMark.tsx          the mark as a React component
├── logo.generated.ts    the pixel grid as data            (generated)
└── index.ts             the only public entry point

The mark is pixel art, so it is not really an image — it is a grid of cells, each one of four kinds. Running the generator over the PNG extracts that grid as typed data, and the component renders it as <svg> rects so it stays sharp at every size.

5. Rules

  • Components import colour from client/src/brand. A raw hex in a component is a bug — it cannot be rethemed and it drifts.
  • The mark renders with shape-rendering: crispEdges and a viewBox in cell units, so it never blurs.
  • Always give the SVG a role and an accessible name, or mark it presentation when the wordmark already says "KinLink".
  • Ship sizes: 16px favicon, 32px nav, 48px app icon, 128px+ hero. One component serves all four.
